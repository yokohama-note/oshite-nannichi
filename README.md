# 推して何日？

小学生の自由研究として作った、スマートフォン向けPWAです。推し始めた日数、予定、記念日、写真などは **利用中の端末・ブラウザ内だけ** に保存されます。外部送信、ログイン、広告、解析、外部カレンダー連携、プッシュ通知はありません。

## 作った順番（研究の記録）

1. 必要な画面と、保存するデータを表にした。
2. 日付を `YYYY-MM-DD` とUTCの「日」だけで計算し、開始日を1日目にした。
3. 初期設定、ホーム、何日目検索、月間カレンダー、設定を作った。
4. 写真を円の中で動かして縮小保存できるようにした。
5. Service Workerで主要ファイルを保存し、オフライン対応した。
6. 15色の同じデザインのアイコンと、色別の追加ページを作った。
7. 日付の自動テストとスマートフォン画面の確認をした。
8. Androidでの保存消失を減らす仕組みと、写真を含めない手動バックアップを追加した。

## データ構造

- 設定: 推し名、自分名、開始日、色、テーマ、縮小済みアイコン
- 予定: ID、名前、日付、任意の時間・メモ、0/5/7日前のお知らせ
- 記念日: ID、名前、基準日、毎年/1回、周年計算、10日前表示
- ホームの飾り: 絵文字の位置・大きさ・回転と、最大3枚の縮小済み写真

すべて IndexedDB の `oshite-db` に保存します。設定・予定・記念日・絵文字は `data`、ホームに貼る写真は `assets` に分けて管理します。入力した名前・予定・メモ・絵文字は安全な文字列として表示し、HTMLとして実行しません。

## ローカル確認

```sh
npm test
python -m http.server 4173
```

Pythonがすでに入っている場合は、上のOS標準機能だけで確認できます。新しいパッケージの取得は不要です。`file://` ではService Workerが動かないため、ローカルサーバーまたはGitHub Pagesで確認します。

## GitHub Pagesで公開（保護者向け）

1. 個人情報や写真がリポジトリに入っていないことを確認する。
2. このフォルダのファイルをGitHubリポジトリへpushする。
3. GitHubの **Settings → Pages** を開く。
4. **Deploy from a branch**、公開ブランチの `/ (root)` を選び保存する。
5. 表示されたURLをスマートフォンで開く。

相対パスだけを使っているため `https://名前.github.io/リポジトリ名/` のサブパスでも動きます。APIキーや秘密情報は不要です。

## お子さん向け使い方

最初にニックネーム、推し始めた日、アイコン、推し色、デザインを選びます。ホームで今日が何日目か見られます。カレンダーの日を押して予定を追加し、「何日目？」で500日目などの日付を調べられます。設定はいつでも変更できます。

## ホーム画面に追加・色を変える

初期設定後の案内、または設定の「ホーム画面のアイコンも変更する」を開きます。iPhoneはSafariの共有から「ホーム画面に追加」、AndroidはChromeメニューの「アプリをインストール」または「ホーム画面に追加」です。

推し色を変えても置いてあるアイコンは自動更新されない場合があります。古い入口をホーム画面から削除し、新しい色のページから追加し直します。**入口の削除ではアプリ内データは消えません。** 設定の「保存データをすべて削除」は別の、元に戻せない操作です。

## 保存についての注意

データは端末内だけで、クラウド同期や自動バックアップはありません。設定画面から写真を含まない手動バックアップを端末へ保存できます。バックアップには名前、予定、メモが含まれるため、他人に見られない場所で保管してください。ブラウザデータやアプリ設定の削除、機種変更、別ブラウザの利用でデータが消えることがあります。アイコン写真は256×256、ホームに貼る写真は最大辺900pxまで縮小し、写真を外部へ送りません。

## 工夫したところ・学んだこと

- 開始日を1日目にするため、日数差に1を足した。
- 時刻ではなくUTCの日付同士を比べ、タイムゾーンによる同日ずれを防いだ。
- 2月29日の毎年記念日は、平年には2月28日と決めて説明を表示した。
- 色だけでなく、文字・チェック・枠も使って選択状態を表した。
- 白・黄・黒でも読めるよう、色ごとに文字色と枠色を変えた。
- `prefers-reduced-motion` で動きを減らす端末設定を尊重した。
- 個人情報をサーバーへ送らずに、ブラウザだけで便利なアプリを作れると学んだ。
